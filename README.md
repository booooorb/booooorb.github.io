# booooorb.github.io

The main screen keeps the original GUI, but each button can now show an imported image.

Replace these files with your own button artwork:

- `assets/button-images/brain-surfing.png`
- `assets/button-images/stroop-typing.png`
- `assets/button-images/ml-visualized.png`

You can keep the same filenames, or edit the `src` values in `index.html` to point at your own PNG, JPG, or SVG files.
