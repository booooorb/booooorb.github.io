# UI assets

Cabinet Grotesk (400, 500, 700, 800) is served locally from `fonts/`.
Source: [Fontshare / Indian Type Foundry](https://www.fontshare.com/fonts/cabinet-grotesk).
Font licensing: [Fontshare licenses](https://www.fontshare.com/licenses).

The favicon is a code-native typographic companion to the Strooptype wordmark.

The locally served GSAP file in `../js/vendor/` is version 3.13.0, downloaded
from the `gsap` npm package via jsDelivr. Its original copyright and license
header is retained. See [GSAP's license](https://gsap.com/standard-license).
